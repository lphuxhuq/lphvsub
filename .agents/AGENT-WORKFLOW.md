# QUY TRÌNH ANTIGRAVITY

## Các command

`/reverse-engineer`
→ Phân tích ngược project

`/new-feature`
→ Phân tích + thiết kế + chia task

`/implement-next`
→ Code đúng một unit

`/review`
→ Review

`/full-cycle`
→ Chạy toàn bộ quy trình có gate
