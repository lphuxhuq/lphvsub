# Plan

Using the verified analysis, write `.codex/plans/master-plan.md` from `templates/master-plan.md`. Include goal, current architecture/behavior, requested behavior, gaps, risks, dependencies, implementation strategy, what will not change, Antigravity and Computer Use strategies, task graph, acceptance criteria, tests, UI/UX checks, rollback, and completion criteria. Create atomic `.codex/tasks/TASK-###.md` files from `templates/task.md`, ordered by dependencies, and mark only unblocked tasks `READY`. Planning does not implement code.
