# Review

Review the diff, task, tests, evidence, and worker report for functional correctness, architecture fit, regression/edge cases, error handling, performance, maintainability, scope, test quality, Antigravity control evidence, and UI/UX evidence. Decide exactly `PASS` or `FAIL` and write `.codex/reviews/<TASK-ID>-review.md` using `templates/review.md`. On FAIL, identify the exact evidence and create a `FIX-###` task; do not patch blindly.
